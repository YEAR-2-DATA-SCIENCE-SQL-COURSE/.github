## Required structure for every group repository

```
your-group-repo/
├── README.md
├── sql/            # SQL scripts, commented, with meaningful file names
├── diagrams/       # ERDs and architecture diagrams
└── sample-data/    # sample data used by the scripts
```

## Required README.md sections

1. Project Title
2. Group Members (full names)
3. Introduction
4. Problem Statement
5. Objectives
6. Research and Key Concepts
7. Technical Approach
8. Database Design and Diagrams
9. SQL Implementation (link to `sql/`)
10. Practical Demonstration and Results
11. Real-World Applications
12. Challenges and Recommendations
13. Future Improvements
14. References
15. Presentation Link (Google Drive)
16. Group Contributions (what each member did)

> PowerPoint files go on **Google Drive**, never on GitHub. Put the shareable link in your README and test it before submitting.

## For group leaders: add your teammate

1. Open your group repository
2. **Settings** > **Collaborators and teams**
3. **Add people** > search the member's GitHub username > choose **Write**
4. The member accepts the invitation sent to their email or GitHub notifications

## Final checklist

- [ ] Project is in the correct group repository
- [ ] Complete README.md in Markdown
- [ ] SQL scripts uploaded and commented
- [ ] Diagrams and sample data included
- [ ] Google Drive presentation link in README and accessible to the lecturer
- [ ] References and individual contributions documented
- [ ] Google Form submitted
- [ ] Every member can explain the project
